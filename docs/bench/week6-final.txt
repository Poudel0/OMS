## Cost of the follower: 1476 -> 1383 orders/sec = 6.3%
# NOT backpressure -- the design makes that impossible (the follower reads log
# FILES; nothing on the matching path waits for it). It is disk contention: the
# follower group-commits its OWN log to the SAME device, so it competes for
# fsync capacity. A follower on its own disk, or on another host, should cost ~0.
# A naive comparison against the 30s/1973-per-sec Week 4 run would have blamed
# the follower for 30%; the control shows most of that gap is deeper books over a
# longer run, not replication.
