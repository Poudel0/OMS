# READING: with the WAL on, throughput FALLS as symbols rise (7012 -> 3134, 2.2x).
# Without the WAL it is flat (~41-45k, within noise). So the loss is entirely in
# durability, not in matching: N sequencers each fsync independently to the SAME
# device, so N symbols means each group commit batches ~1/N as many orders and
# the fixed per-fsync cost is amortised that much less. Partitioning buys
# matching parallelism and COSTS durable throughput on shared storage.
# Per-symbol batch sizes were not instrumented in this run; the no-WAL control is
# what pins the cause to fsync rather than to contention.
